**Proyecto 4: Etapa 4. Etapa final**
Coffe Shop

## 🚀 Características del Proyecto

Este proyecto es una Landing Page Landing page responsiva para una cafetería de especialidad, construida con HTML5 y CSS3 bajo la metodología BEM. El proyecto destaca por su arquitectura modular y escalable, implementando secciones de contenido dinámico, galerías multimedia y un sistema de reservaciones optimizado para la experiencia de usuario.

## 🛠️ Tecnologías y Metodologías

- **HTML5 Semántico:** Estructura optimizada para SEO y accesibilidad.
- **CSS3 Avanzado:** Uso de variables, herencia y posicionamiento absoluto/relativo.
- **BEM (Block Element Modifier):** Convención de nombres para un CSS mantenible.
- **@import:** Sistema de gestión de estilos modular.

## 📈 Próximas Mejoras (Roadmap)

Este proyecto busca mejorar. Las siguientes funcionalidades están planeadas para futuras versiones:

- [ ] **Confirmación por Email:** Integración con servicios de mensajería para enviar confirmaciones automáticas de reserva.
- [ ] **Gestión de Disponibilidad:** Conexión a una base de datos para mostrar solo horarios disponibles en tiempo real.
- [ ] **Animaciones de Interfaz:** Implementación de librerías como AOS para efectos de scroll.
